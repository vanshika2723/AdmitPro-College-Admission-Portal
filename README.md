# AdmitPro – College Admission Portal

A modern and responsive college admission portal designed to simplify the college admission process through a clean, user-friendly interface.

## 🌐 Live Demo

[View AdmitPro Website](https://vanshika2723.github.io/AdmitPro-College-Admission-Portal/#dashboard)

## 📌 Project Overview

AdmitPro is a college admission portal website developed as part of the **WD-COL-004 – College Admission Portal** project task. It provides a centralized interface for exploring admission-related information and accessing the portal dashboard.

## ✨ Features

- Modern and user-friendly interface
- College admission portal dashboard
- Responsive website layout
- Simple navigation between website sections
- Clean and organized user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages
